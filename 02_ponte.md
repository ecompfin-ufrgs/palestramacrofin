# 🌉 2. A Ponte de Ouro: Deixando o IS-LM Dinâmico

Se você cursou Macro 1 provavelmente desenhou as curvas **IS** e **LM** no papel.

$$\text{IS: } Y = C(Y-T) + I(r) + G$$
$$\text{LM: } \frac{M}{P} = L(Y, i)$$

### 🛑 O Problema do IS-LM Tradicional para o Mundo Real
1. **É Estático:** Tudo acontece no mesmo período de tempo. Não há amanhã, não há planejamento de longo prazo.
2. **Falta de Microfundamentos:** O consumo $C$ e o investimento $I$ usam "regras de bolso" fixas, ignorando que pessoas mudam de comportamento quando o cenário muda.
3. **Sem Crescimento:** O PIB potencial cai do céu como uma variável exógena.

### 🚀 A Evolução para o Crescimento Endógeno com Capital Humano
Para consertar isso, a macroeconomia conectou o curto prazo monetário aos modelos de crescimento neoclássicos:
* O PIB não cresce só porque o tempo passa, mas porque os agentes acumulam **Capital Humano** (educação/habilidade) e **Tecnologia**.
* As funções de consumo e investimento passam a ser decisões ótimas de famílias (que escolhem poupar ou consumir pensando no futuro) enfrentando **choques aleatórios** de produtividade.

```
[IS-LM Estático] ➔ [Escolha Intertemporal Poupança/Consumo] ➔ [Choques de Capital Humano] ➔ [DSGE]
```
